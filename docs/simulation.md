# 模拟规则说明

> 产品定位: 英雄联盟对线期决策模拟器——给定一个对线场景，告诉用户怎么出装、怎么打，胜率最高。
> v1 范围: 2 英雄 / 5 装备 / 等级 1~10 / 3 种打法 / 100~1000 次模拟

## 0. 两种模式

- **A 手动试玩**: 用户每回合亲手选择行动；引擎记录选择，输出"你的打法倾向"（如换血频率 70% ≈ 偏激进）
- **B 自动模拟（主线）**: 用户选定打法 + 候选装备；引擎按打法概率自动选择行动，1000 局 Monte Carlo → 各装备胜率 → 推荐 + AI 解读
- **教练模式（v2）**: A 的实局表现 vs B 的最优策略对比，AI 给出差异解读

两种模式共用同一个引擎，区别只在"谁做选择"（ActionChooser 接口: 策略实现 / 真人实现）。

## 1. 模拟边界

### 初始状态
- 双方英雄由用户选择（对手可随机），段位（双方水平）由用户输入
- 双方等级 = 用户输入的等级（1~10），金币 = 用户输入的金币
- ⚠️ 待确认: 开局购买候选装备的细节（买一件？扣多少金币？）
- 击杀 0 / 死亡 0

### 结束条件
- 某一方先到达 10 级，或
- 碾压判定: 一方同时满足 经济领先 ≥ 2000 且 人头领先 ≥ 3
- 因为: 10 级足以看出对线优劣；碾压条件让悬殊对局提前结束，避免无效模拟

### 世界内只有
我方英雄、对手、双方小兵

### 明确排除（v1）
防御塔、打野 gank、回城购物、游走支援、卡线机制

### 版本规划
- v2: 打野 gank 随机事件、自适应打法策略（低血量转稳健）、"打法自动推荐"开关、卡线机制
- v3: 防御塔、回城购物

## 2. GameState 字段

### 静态（由英雄 + 等级决定，来自数据文件，引擎只查不写）
- 基础攻击力、法术强度、护甲、魔抗、最大生命、最大法力

### 动态（每步结算，引擎读写）
- 当前 HP、当前法力
- 经验值（每步累积，经验够到达对应等级就升级）
- 等级（由经验值推出，1~10）
- 金币、装备列表
- 击杀数、死亡数（死亡后跳过若干回合，复活回线）
- 当前步数 / 波次

### 环境（第三方，不属于任何一方）
- 当前波次、双方线上剩余小兵数

### 输入参数（一局不变，不属于状态）
- 英雄、对手、段位、打法（B 模式）

> 原则: 字段只存原始数据；"当前属性值""实力差距"等派生量每次现算，不存。

## 3. 时间推进

固定步长，30 秒一步 = 一回合。因为小兵 30 秒一波，步长对齐小兵波，每步结算一次经验 / 补刀 / 换血。

## 7. 结束判定与统计量

- 每局结束判"赢 / 输"（⚠️ 待设计: 综合优势得分公式，候选思路: 经济差 + 人头差 × 系数 − 死亡差 × 系数）
- 1000 局 → 胜率 = 赢局数 / 1000
- 辅助统计: 平均经济、平均伤害、平均击杀、平均死亡、存活率、关键事件
- 输出: 候选装备胜率对比 → 推荐最优 → AI 解读

## 附录: 对线机制速成

- 小兵波: 每 30 秒双方各出一波约 6 个小兵，在线上互相消耗
- 补刀: 击杀残血小兵得约 20 金币——对线期金币的主要来源
- 经验: 每回合获得基础经验，补刀和人头提供额外经验（具体数值 Q5 定）
- 换血: 双方互相打掉对方 HP，由属性和打法决定频率与胜负
- 死亡: HP 归零 = 死亡，复活后走回线上继续（对线期不是一命通关）
